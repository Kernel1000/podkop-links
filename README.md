# podkop-links

Управляющий Telegram-бот для серверов 3x-ui и автообновление vless-ссылок на роутерах OpenWrt с podkop.

```
Ты ──► podkop-bot (управляющий сервер)
          │ SSH (ключ бота)
          ├──► сервер слота 1 ─┐  бот забирает базу 3x-ui,
          ├──► сервер слота 2 ─┤  собирает ссылки клиентов с меткой «router»
          └──► сервер слота N ─┘
          │
          └──► GitHub (приватный репозиторий): routers/<имя роутера>.txt
                         ▲
                роутеры: podkop-links-sync (cron, 10 мин)
```

* Этот репозиторий (код) — **публичный**, секретов в нём нет.
* Ссылки лежат в отдельном **приватном** репозитории, например `router-links`.
* Роутер в 3x-ui = клиент с меткой `router` в поле **Comment**. Его Email = имя роутера, одинаковое на всех серверах (латиница, цифры, `._-`).
* Слот = место сервера. Сколько слотов — столько ссылок у каждого роутера. Заблокировали сервер — добавляешь новый в тот же слот.
* Метка ссылки, как в 3x-ui: `название inbound-Email` (например `#vlessDE-mama_home_router`). Название inbound задаётся в панели.
* Файл роутера: перед каждой ссылкой строка `# slot N` — по ней бот знает слот; роутер читает только строки `vless://`.

## Управляющий сервер (бот)

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Kernel1000/podkop-links/main/install.sh)
```

Спросит токен бота от @BotFather, твой Telegram ID (найдёт сам), приватный репозиторий и GitHub-токен с правом записи (Contents: Read and write).

* Повторный запуск — обновление кода, настройки сохраняются. Перенастроить: добавить `--reconfigure`.
* Лог: `journalctl -u podkop-bot -f`
* Настройки и данные: `/etc/podkop-bot/` (config.env, servers.json, SSH-ключ бота)

**Кнопки:** 🖥 Серверы (состояние, слот, удаление) · ➕ Добавить сервер (IP + пароль root, бот ставит свой ключ, сообщение с паролем удаляет) · 🚀 Выгрузить ссылки (с подтверждением и списком изменений) · 📊 Статус ссылок.

Защита при выгрузке: сервер не отвечает или на нём нет роутера — для этого слота остаётся прежняя ссылка.

## Роутер (OpenWrt + podkop)

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/Kernel1000/podkop-links/main/router/install.sh)"
```

Нужен отдельный GitHub-токен **только на чтение** (Contents: Read-only) для приватного репозитория со ссылками.

* Раз в 10 минут роутер проверяет только номер последнего коммита; свой файл качает, лишь когда он сменился
* Проверить: `podkop-links-sync --dry`, принудительно: `podkop-links-sync --force`
* Лог: `logread -e podkop-links`

GitHub недоступен или файла роутера нет — ничего не меняется.
